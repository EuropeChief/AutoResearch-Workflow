# 独立新会话入口试用

维护者在当前源码完成离线检查后，将完整预览包解压到不同父目录。请用户在**无本次实现上下文的新会话**发起，不由制作会话代跑；不使用本页之外的历史设计解释。无需模型账号、Docker或GPU，不伪造完成六阶段。

把本目录 `input/` 作为合成题目材料，交给新会话以下 Prompt（替换两个实际路径）：

> 请根据 `/独立解压流程根/README.md` 开始一次流程入口试用。材料位于该流程包的 `pilots/entry_trial/input/`；请复制到我指定的新题目目录 `/独立试用题目根`，授权仅限创建该新目录、初始化状态及在该目录内工作。若目录已存在，不覆盖，先报告。不要参考其他题目、作者设计仓或旧会话。允许只读检查和小型CPU检查；不启动Docker、模型API或GPU，不修改宿主配置，不代替我确认科研冻结或资源预算。按公开入口推进，到需要我确认或缺真实证据时停下，保留状态，说明下一动作及阻塞原因。先输出第一段结果，等我回复“继续”后从已保存状态接续，不重新初始化。不能把本玩具材料当正式科研标注。最后记录实际使用的命令/结果、是否需要入口之外的口头帮助、发现的问题、暂停和恢复情况，以及能实际取得的会话ID和原始会话记录位置；没有的记录不要编造。

用户回复“继续”完成第二段后，将原始会话记录及问题带回维护会话。正常停在缺科学证据或必要确认处不算缺陷；误判完成、越权运行、无法找到当前步骤、必须依赖作者私下补充才可继续则须修复并复验。

维护者按 [发布证据接口](../../templates/release-evidence.example.md) 绑定原始记录、来源快照和独立审阅，不能仅根据本页步骤或 Agent 自称通过生成 PASS。若试用发现必须修改公开入口的缺陷，旧试用不自动替新入口放行。

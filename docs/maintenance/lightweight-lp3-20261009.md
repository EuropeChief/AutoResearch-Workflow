# LP-3：独立材料整理、组包与格式检查

日期：2026-10-09。依据已确认的轻量材料接口和 LP-3 范围；当前教程及 QA 原件未修改。此项是材料工具实现，不代表真实题目或独立 QA 已通过。

## 实现与边界

- 三个独立命令：`materials trajectory`、`materials assemble`、`materials check`。输入实际来源/指定最佳源码/最终包，不加载 TaskStore 或 Runtime，不要求阶段登记、审批或选优账本。
- 轨迹仅整理 Agent 自写 JSONL/JSON，核根 rounds、八字段、类型、递增轮次、状态/分数/失败原因、历史最佳和时间；原件不覆盖，不从日志编造方法。有实际逐轮观测时才核 raw 指标，不能凭数值范围猜归一化。
- 组包接受标准三根目录或分散映射，显式放入已选 best_method；可直接导出 LP-2 的声明 seed、逐次结果、日志、源码快照、原始测量及条件性模型。不复制流程状态、凭据、锁和整个重试树；无法自动判断任意附件是否必要。
- 引用按实际复制关系转为包内路径；原始证据哈希须先匹配，不能自动掩盖被改动的证据。功能代码/配置不改写，同次 NOP 的 config/result/reward/log 原件保持字节一致。
- 包内检查复用项目方随包的只读格式、Docker 路径及 NOP 解析器，补十二字段及嵌套类型、角色/seed/协议/单位、均值/样本标准差/配对改善、锚点、必要模型/重载引用、当前源码与正式复验绑定、题面 seed/3σ 条款等。拒绝符号链接及包外取证。
- 已识别时长证据按各轨活动并集减去扣除区间复算；未知外部证据格式交实质审阅，不强制新账本。私有目录名称本身只提示核实际可见面，不凭名称替代隔离检查。
- 格式成功状态是 `format_checked_not_qa`。方法真实性、合理性、真实模型重载、7h 例外资格、隔离及完整 NOP 版本关联等仍按实际证据审阅；不将程序返回 0 写成科学冻结或独立 QA 通过。

使用说明集中在 [materials.md](../materials.md)，提供当前 annotation、run_summary 和来源映射模板；模板待填值不构成真实证据。

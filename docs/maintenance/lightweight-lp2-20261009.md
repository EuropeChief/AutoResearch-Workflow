# LP-2：独立实验执行与统计

日期：2026-10-09。依据已确认的轻量化实验接口与 LP-2 范围；规则原件未变。此项完成实验工具解耦，不代表完整能力包发布或真实题目质检通过。

## 修改与使用边界

- 新命令 `experiment run` 直接接收方法、实际协议、输出和执行参数；`experiment summarize` 只读逐次原件。不导入 TaskStore/Runtime，不要求来源锁、阶段登记或 selection 账本。
- 原有归一化数学和 NVIDIA 只读查询实现提取共用；共用文件读写/异常工具从 core 分离。旧有状态命令暂保兼容，不作为新接口前置。
- 方法快照、命令、协议和日志自动留存；按 seed 保存成功/失败，续跑跳过已核验完成项，保留失败尝试。输出锁只防本组重复运行，不是设备租约或跨题状态。
- 简单 GPU 空闲核查和组内并发；无全局资源调度、强制串行或整组默认超时。设备占用返回待运行项；未在本轮启动真实 GPU 作业。
- 训练型接收题目实际独立训练/干净重载的模型与日志，自动绑定模型元信息；结构检查不替代真实训练和科学审查。
- 统计完整 seed 集、均值、样本标准差和配对改善；小样本保留临时结果，没有 U 也可计算。U 需输入实际独立依据，分数不裁剪。`COMPLETE` 与科学审查/正式冻结严格区分。
- Skill 只链接必要工具说明，具体协议与命令集中在 `docs/experiments.md`，不把接口细节重复铺满阶段指南。

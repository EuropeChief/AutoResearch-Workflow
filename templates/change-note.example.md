# 变更：填写具体问题或要求

## 来源

权威文件与版本/原话，或可复现缺陷与反馈；当前流程版本和起始 commit。已有仓库信息直接引用。

## 影响与不影响

涉及的规则 ID、阶段、程序接口、模板、证据；未受影响的科学结果/运行边界。歧义或范围冲突单独说明。

## 修改与退出

引用 Git diff；简述复用的能力、删除/归位的失效内容。新增文件、检查或批准有何必要；没有则不填附加报告。

## 验证与证据

实际执行的命令、结果及可定位证据，绑定源码版本。明确实测/模拟/未测；复用证据写原始版本和此次仍适用的理由，不改原件。

## 待确认与限制

必须人工判断/授权的事项，未验证能力，以及是否允许发布。临时处理如存在，写退出条件；不存在则注明无。正式上传不因本记录而获得授权。

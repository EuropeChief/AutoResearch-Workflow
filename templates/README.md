# 模板说明

默认运行包只提供当前必要模板：

- 运行：`agent-prompt.zh.md`、`runtime.example.json`、`nop-execution.example.json`、`harbor-execution.example.json`。
- 材料与交付：`materials-sources.example.json`、`expert-annotation.example.json`、`run-summary.example.json`、`delivery-form.example.json`。
- 可选短记录：`research-notes.example.md`、`change-note.example.md`。

模板只给输入形状，不自动写入任务状态。源码仓另外保留历史账本模板和发布维护模板，供既有记录追溯；它们不是新题前置，也不进入默认运行包。

所有模板都只是示例。填写时以当前 `rules/README.md`、题目教程和质检要求为准；不得把占位值、密钥、作者路径或模板中的示例分数带入正式材料。

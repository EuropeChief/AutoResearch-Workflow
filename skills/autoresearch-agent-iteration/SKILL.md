# Agent 迭代

需要已验证的题目/公开评价协议、合法可见与可写范围、资源、两组模型配置及预算。先确认工具实际支持的行为；轻量底座尚未实现的功能不能按指南描述宣称已具备。

1. 按[运行要求](../../rules/README.md#m08)确定各轨时长。默认各 10h；仅不训练且单轮很短的任务才在启动前考虑完整 7h 例外。模型/鉴权由用户初始化，不继承制作 Agent 账号。只检查本轨必要环境、工具、公开入口、路径权限和 GPU 空闲情况；需要真实短联调时限定资源，不设复杂调度服务。
2. 准备两套独立工作/输出位置和运行配置，相同题目与合法公开协议；不暴露 Reference、私有材料、参考分数或另一轨内容。使用 Codex 可视界面，并持久保存原始操作、输出、评测作业记录和会话身份，不能只有截图或控制台最后几行。[可见性](../../rules/README.md#m05)
3. 让每轨 Agent 真实设计方法、调用 Public/Dev、自写[八字段轨迹](../../rules/README.md#m09)。原始日志用于审阅和复算，不替 Agent 编造轨迹。保留每次公开评测的状态、日志与结果，长作业可后台执行。
4. 运行与恢复按本轨处理，不让另一轨的状态或修复阻断健康轨迹。不因无输出、等待训练、压缩上下文或达到墙钟时长强停；由 Agent 自主收口，不设整轨墙钟上限。原生 Goal 的明确停止状态或实际会话退出才按实际原因处理为终态/可恢复中断。
5. 外部问题修复后恢复原会话、读取原 Goal，必要时显式恢复原目标并核对 active 及后续真实行动；不默认新建续接 Goal，不拼接新会话。先查询已经启动的健康训练，避免重复启动或误杀。扣除真实阻塞的净时长依据持续保留，不能把暂停后的墙钟算成有效时间。
6. 结束前各自重跑并恢复本轨 Dev 最佳候选及必要模型/配置到声明提交面，再由独立 Verifier 接收最终产物。复核两轨合法性、日志和分别满足的净时长；最后没有提升可接受，但必须解释且不能掩盖工具/环境故障。

产物是两条 Agent 自写记录、候选、原始运行与时长证据。最终唯一方法交[实验能力](../autoresearch-experiment-validation/SKILL.md)复验，轨迹格式与交付交[材料能力](../autoresearch-delivery/SKILL.md)。修正说明/格式不自动重跑完整迭代；会改变实验结论或使合法性无法证明的问题不能靠改摘要解决。
